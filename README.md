## Deploy to Vercel
1. Push to GitHub. 2. vercel.com > Add New Project > import the repo.
3. Framework: Vite (auto-detected), build `npm run build`, output `dist`. Deploy.
CLI alternative: `npm i -g vercel && vercel --prod`.
